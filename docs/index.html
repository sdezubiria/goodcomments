GoodComments
Hanging
To check
The pile

Three states. Nothing else to learn.

Not tied to pull requests or commits: it's a simple way to see what's been asked, what's been done, and what you've checked.

01

Open

Hang a comment from the column, the terminal (gc add), a forwarded email, a Slack command or a WhatsApp share. Paste a screenshot with it.

02

Fixed

You or an agent makes the change and pulls the stick: the card drops to “To check” with a note on what changed and where.

03

Done

You check it and approve: it falls onto the pile, which grows as the project gets done. Not right yet? Reopen it with a screenshot.

See it in action.

Real screenshots of the column (with made-up projects). Everything you need to follow up on feedback, at the edge of your screen.

~/northwind $ gc show 17
#17 · [open] · northwind · from Client · 5m ago
  Footer still shows the old contact email
  where: northwind.example/contact
  attachments: northwind.png
  fix (claude, 5m ago): Updated footer.html with the new address
  REOPENED (you, 5m ago): The contact page still has the old address — see northwind.png

~/northwind $ gc fix 17 "Replaced the address in contact.html too"
#17 → fixed

What an agent sees from inside the repo: the comment, the reason it came back, and the screenshot.

Built for your agents, too.

An MCP server and a CLI that any agent can use. Inside a repo, they find that project's comments on their own.

  • List, add and note comments, and see the screenshots attached to them.
  • Mark fixed with a note of what changed, so checking takes seconds.
  • Only you mark done. Agents can't close their own work.
  • Live: when an agent fixes something, you see the card fall.
# one time: give Claude Code the tools
claude mcp add goodcomments -s user -- \
  node ~/.goodcomments/app/bin/gc.js mcp

# or use the CLI from any agent or script
gc                       # this repo's open comments
gc show 12
gc fix 12 "Resized the hero in header.php"
gc add "Footer link 404s" -f shot.png

Small, local, yours.

A tiny server with no dependencies, a column that lives at the edge of your screen, and data that stays on your machine until you want it in the cloud.

At the edge of your screen

Rest the pointer on the right edge or press ⌃⌥C. Keep it open, minimize it, or drag to resize it.

Projects by folder

Point a project at a repo and everything run inside it picks the right one automatically.

Screenshots everywhere

Paste or drop images into a comment, a fix or a reopen. Agents get them as images.

Comments from anywhere

A webhook inbox for email services, Slack slash commands, Shortcuts and scripts.

Local first, cloud later

SQLite on your Mac today; a Dockerfile and Turso support when you want it hosted.

Poke the monkeys

They have opinions. Throw the ones on the pile around. There may be bananas.

Install in one line.

Paste this in Terminal. It downloads GoodComments, adds the gc command, builds the menu bar app and, if you use Claude Code, connects it. Run it again any time to update.

curl -fsSL https://raw.githubusercontent.com/sdezubiria/goodcomments/main/install.sh | sh

Or with Homebrew:

brew install sdezubiria/goodcomments/goodcomments

Needs macOS 13+, Node.js 22.13+ and Apple's Command Line Tools (xcode-select --install).

Prefer to set it up by hand? 
git clone https://github.com/sdezubiria/goodcomments.git
cd goodcomments
npm start                     # the board at http://127.0.0.1:4477
npm link                      # puts `gc` on your PATH
npm run mac && open mac/build/GoodComments.app

# start a project from a repo
cd ~/Code/my-site && gc project add "My site" --path .
